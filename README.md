# Philip Bankier

I’m a co-founder of [Kairox AI](https://kairoxai.live/), building [ActRun](https://actrun.ai/). I’m interested in what it takes for AI agents to follow a task through to completion.

My background spans software development, DevOps, analysis and developer relations. I tinker daily, especially with the context and tools agents need to do useful work.

## Selected public work

| Project | What it does |
| ------- | ------------ |
| [Cross-Agent Memory](https://github.com/philipbankier/cross-agent-memory-public) | Search across AI-assistant histories and trace answers back to the original messages. Self-hosted, early-stage software. |
| [TasteKit](https://github.com/philipbankier/tastekit) | Capture how you want agents to work, then export those preferences as portable instructions. Currently pre-1.0. |
| [Awesome Agent Skills](https://github.com/philipbankier/awesome-agent-skills) | A directory of skills, tools and plugins across AI-agent ecosystems. |
| [technical-visualizer](https://github.com/philipbankier/technical-visualizer) | Turn technical sources into visual drafts with inspectable source context. |

I also work on [PromptCache](https://promptcache.live/), a directory for discovering and sharing AI prompts.
